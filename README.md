🤖 IoT-Based Smart Supermarket Restocking Robot Using ESP32

📌 Project Overview

The IoT-Based Smart Supermarket Restocking Robot is designed to automate the transportation of products from the storeroom to supermarket aisles. It monitors shelf stock levels and identifies products that need restocking.

When a product is low or out of stock, the system sends a restocking request to the robot. The robot travels to the storeroom, where the required product information and quantity are displayed. After loading the products, the worker presses a confirmation button, and the robot returns to the required aisle.

🔄 Working Principle

The system monitors supermarket shelf stock levels.
Low-stock or empty products are identified.
A restocking request is sent to the robot.
The robot travels automatically to the storeroom.
The display shows the required products and quantities.
The storeroom worker loads the products and presses the confirmation button.
The robot returns to the required supermarket aisle.
The aisle worker places the products on the shelves.

🏗️ System Architecture

The system consists of four major sections:
Detection Unit: Identifies low-stock or empty shelves.
Processing Unit: Processes stock information and controls the robot.
Communication Unit: Uses Wi-Fi for IoT-based communication.
Robot Unit: Transports products between the storeroom and supermarket aisles.
